# SAG Defence and Aerospace

Official web platform for **SAG Defence and Aerospace Pvt Ltd** — pioneering sovereign Indian unmanned combat systems, high-altitude tactical ISR platforms, counter-UAS interceptors, and missile air defence systems.

## Key Features

- **Cinematic Aerospace Video Loader**: Full-screen video loader with real-time telemetry checks, progress indicators, and instant skip controls.
- **Dynamic Text Scroll Effects**: Section-specific kinetic typography, perspective reveals, HUD scan animations, and radiant Sanskrit mottos.
- **Sovereign Systems Portfolio**: Comprehensive technical specifications, multi-angle renders, and datasheets:
  - **SAG RAZOR P1**: High-speed tactical FPV kamikaze strike drone.
  - **SAG RAZOR OFC**: Fiber-optic guided combat UAV immune to EW jamming with zero RF emissions.
  - **SCOUT-X**: Persistent tactical ISR quadcopter with thermal terminal sensors.
  - **AERON A1**: Long-endurance VTOL hybrid fixed-wing surveillance platform.
  - **DOOM MK-1**: Short-range supersonic SAM / Counter-UAS missile system.
  - **SAG VELOCITY**: High-velocity autonomous counter-drone interceptor.
- **Technology Roadmap**: Strategic development phases including Mach 1+ loitering munitions, solid-propellant rocket propulsion, and mesh-networked swarms.
- **Leadership**: Aerospace engineering directors and veterans guiding sovereign defense autonomy.
- **Classified Briefing Portal**: Direct technical liaison channels and briefing request modal.

## Technology Stack

- **Framework**: React 18, Vite, TypeScript
- **Styling**: Tailwind CSS with custom stealth aerospace design tokens
- **Animations**: GSAP (GreenSock), ScrollTrigger, Framer Motion
- **Icons**: Lucide React

## Development

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Build for production
npm run build
```
