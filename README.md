# SAG Defence and Aerospace

Official web platform for **SAG Defence and Aerospace Pvt Ltd** — pioneering sovereign Indian unmanned combat systems, highaltitude tactical ISR platforms, counterUAS interceptorsandmissile air defence systems.

## Key Features

 **Cinematic Aerospace Video Loader**: Fullscreen video loader with realtime telemetry checks, progress indicatorsandinstant skip controls.
 **Dynamic Text Scroll Effects**: Sectionspecific kinetic typography, perspective reveals, HUD scan animationsandradiant Sanskrit mottos.
 **Sovereign Systems Portfolio**: Comprehensive technical specifications, multiangle rendersanddatasheets:
   **SAG RAZOR P1**: Highspeed tactical FPV kamikaze strike drone.
   **SAG RAZOR OFC**: Fiberoptic guided combat UAV immune to EW jamming with zero RF emissions.
   **SCOUTX**: Persistent tactical ISR quadcopter with thermal terminal sensors.
   **AERON A1**: Longendurance VTOL hybrid fixedwing surveillance platform.
   **DOOM MK1**: Shortrange supersonic SAM / CounterUAS missile system.
   **SAG VELOCITY**: Highvelocity autonomous counterdrone interceptor.
 **Technology Roadmap**: Strategic development phases including Mach 1+ loitering munitions, solidpropellant rocket propulsionandmeshnetworked swarms.
 **Leadership**: Aerospace engineering directors and veterans guiding sovereign defense autonomy.
 **Classified Briefing Portal**: Direct technical liaison channels and briefing request modal.

## Technology Stack

 **Framework**: React 18, Vite, TypeScript
 **Styling**: Tailwind CSS with custom stealth aerospace design tokens
 **Animations**: GSAP (GreenSock), ScrollTrigger, Framer Motion
 **Icons**: Lucide React

## Development

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Build for production
npm run build
```
